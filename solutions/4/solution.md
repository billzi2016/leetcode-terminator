## 解法一：暴力 / 最直觉解  

**思路**  
> 当我们第一次看到「两个有序数组的中位数」时，最自然的想法就是把两个数组全部放在一起，排成一个完整的有序序列，然后直接取中间的数（或中间两个数的平均值）。  
> 这相当于把「合并」和「排序」这两件事一步完成——因为两个数组本身已经是排好序的，只要像归并排序的合并过程一样，从小到大依次挑选元素，就能得到完整的有序数组。最后根据总长度的奇偶性返回相应的中位数即可。

**涉及的知识点**  
1. **数组遍历**：顺序访问数组中的每个元素，常用 `for` 循环或指针（索引）实现。  
2. **双指针（Two‑Pointer）**：维护两个指针分别指向 `nums1` 与 `nums2` 的当前位置，每次比较指针指向的值，取较小的放入结果数组并移动对应指针。  
3. **中位数的定义**：如果总长度为奇数，中位数是第 `len/2`（向下取整）个元素；如果为偶数，则是第 `len/2−1` 与第 `len/2` 两个元素的平均值。  

**逐步拆解**  
1. 读取两个数组的长度 `m`、`n`。  
2. 创建空列表 `merged` 用来存放合并后的有序序列（也可以不创建，只保留到达中位数时的两个值）。  
3. 初始化两个指针 `i = 0`（指向 `nums1`）和 `j = 0`（指向 `nums2`）。  
4. 进入循环：只要 `i < m` 且 `j < n`，比较 `nums1[i]` 与 `nums2[j]`，把较小的数 `append` 到 `merged`，并将对应指针右移一位。  
5. 当其中一个数组已经遍历完后，把另一个数组剩余的所有元素一次性 `extend` 到 `merged`（因为它们本身已经有序）。  
6. 计算总长度 `total = m + n`。  
   - 若 `total` 为奇数，返回 `merged[total // 2]`。  
   - 若 `total` 为偶数，返回 `(merged[total // 2 - 1] + merged[total // 2]) / 2.0`。  

**代码**  

```python
class Solution:
    def findMedianSortedArrays(self, nums1, nums2):
        # 1. 记录两个数组的长度
        m, n = len(nums1), len(nums2)

        # 2. 用来存放合并后的有序数组
        merged = []

        # 3. 初始化双指针
        i = j = 0

        # 4. 同时遍历两个数组，比较当前指向的元素大小
        while i < m and j < n:
            if nums1[i] <= nums2[j]:
                # nums1 当前元素更小或相等，放入 merged 并右移指针 i
                merged.append(nums1[i])
                i += 1
            else:
                # nums2 当前元素更小，放入 merged 并右移指针 j
                merged.append(nums2[j])
                j += 1

        # 5. 处理剩余元素（只会有一个数组还有未遍历的部分）
        if i < m:
            # nums1 还有剩余，直接追加到 merged
            merged.extend(nums1[i:])
        if j < n:
            # nums2 还有剩余，直接追加到 merged
            merged.extend(nums2[j:])

        # 6. 计算中位数
        total = m + n
        if total % 2 == 1:
            # 奇数长度，直接返回中间元素
            return float(merged[total // 2])
        else:
            # 偶数长度，返回中间两个元素的平均值
            left = merged[total // 2 - 1]
            right = merged[total // 2]
            return (left + right) / 2.0
```

**举例走一遍**（`nums1 = [1,3]`，`nums2 = [2]`）  

| 步骤 | i | j | merged（已合并） | 说明 |
|------|---|---|-----------------|------|
| 初始化 | 0 | 0 | [] | `m=2, n=1` |
| 第1次循环比较 `nums1[0]=1` 与 `nums2[0]=2`，1 ≤ 2 → 把 1 加入 `merged`，i→1 | 1 | 0 | [1] | 取 `nums1` 的元素 |
| 第2次循环比较 `nums1[1]=3` 与 `nums2[0]=2`，3 > 2 → 把 2 加入 `merged`，j→1 | 1 | 1 | [1,2] | 取 `nums2` 的元素 |
| 循环结束（j 已到达 n） | 1 | 1 | [1,2] |  |
| 处理剩余：`i < m` 为真，`nums1[1:] = [3]` 追加 | — | — | [1,2,3] | 合并完毕 |
| 计算中位数：total = 3（奇数） → `merged[1] = 2` | — | — | — | 返回 2.0 |

**复杂度分析**  
- **时间复杂度**：`O(m + n)`。我们遍历两个数组各一次，最多进行 `m + n` 次比较与插入操作。  
- **空间复杂度**：`O(m + n)`。需要额外的数组 `merged` 来保存所有元素（如果只保留到达中位数的前半段，可以降到 `O(1)`，但代码可读性会下降，这里保持直观的 `O(m+n)` 实现）。

## 解法二：最优解  

**核心洞察**  
暴力解的瓶颈在于**把所有元素都合并**，即使我们只需要中间的一个或两个数。观察到两个数组都是有序的，我们可以通过**划分**的方式直接定位中位数所在的“左半边”和“右半边”。  
关键是找到一个划分点 `partitionX`（在较短数组上），使得：  

```
maxLeftX ≤ minRightY   且   maxLeftY ≤ minRightX
```

其中 `X`、`Y` 分别是较短数组和较长数组。满足这两个不等式时，左半边的最大值就是中位数（奇数）或左半边最大值与右半边最小值的平均值（偶数）。因此，只要在较短数组上做二分搜索，就能在 `O(log(min(m,n)))` 时间内定位划分点。

**涉及的知识点**  
1. **二分搜索（Binary Search）**  
   - **定义**：在有序序列中，通过每次将搜索区间折半来快速定位目标值的技术。  
   - **核心操作**：比较中间元素与目标，决定在左半段还是右半段继续搜索，时间复杂度为 `O(log N)`。  
   - **为什么能解决本题**：我们把「划分位置」视作要搜索的目标，只要判断当前划分是否满足上述不等式，就可以决定向左或向右移动，快速收敛到正确划分。  
2. **极端值（正负无穷）**  
   - 在划分边界可能出现「左半边为空」或「右半边为空」的情况，需要用 `-inf` / `+inf` 作为哨兵，使比较公式统一且不失效。  

**逐步拆解**  
1. 设 `A = nums1`（长度 `m`），`B = nums2`（长度 `n`）。如果 `m > n`，交换两数组，使 `A` 为较短数组。  
2. 计算总长度 `total = m + n`，以及左半边需要的元素个数 `half = (total + 1) // 2`（向上取整，保证左半边比右半边多或相等）。  
3. 初始化二分搜索区间：`left = 0`，`right = m`（在 `A` 上划分）。  
4. 循环直到找到满足条件的划分：  
   - `i = (left + right) // 2` → `A` 的划分位置（左边有 `i` 个元素）。  
   - `j = half - i` → `B` 的划分位置（左边有 `j` 个元素），保证左半边总元素数为 `half`。  
   - 计算四个边界值：  
     - `A_left = A[i-1]`（若 `i==0` 用 `-inf`）  
     - `A_right = A[i]`（若 `i==m` 用 `+inf`）  
     - `B_left = B[j-1]`（若 `j==0` 用 `-inf`）  
     - `B_right = B[j]`（若 `j==n` 用 `+inf`）  
   - 检查划分是否合法：  
     - 若 `A_left ≤ B_right` 且 `B_left ≤ A_right` → 找到答案，退出循环。  
     - 否则，如果 `A_left > B_right`，说明 `A` 的划分太右，需要左移：`right = i - 1`。  
     - 否则（`B_left > A_right`），说明 `A` 的划分太左，需要右移：`left = i + 1`。  
5. 循环结束后，根据总长度奇偶性返回结果：  
   - **奇数**：`median = max(A_left, B_left)`。  
   - **偶数**：`median = (max(A_left, B_left) + min(A_right, B_right)) / 2.0`。  

**代码**  

```python
class Solution:
    def findMedianSortedArrays(self, nums1, nums2):
        # 1. 让 nums1 成为较短的数组，方便在其上二分
        if len(nums1) > len(nums2):
            nums1, nums2 = nums2, nums1   # 交换引用

        m, n = len(nums1), len(nums2)

        # 2. left 表示在 nums1 中划分左边的元素个数的下界，right 为上界
        left, right = 0, m
        # 3. half 为左半边需要的元素总数（向上取整）
        half = (m + n + 1) // 2

        while left <= right:
            # 4. 在 nums1 上尝试划分 i，nums2 上对应划分 j
            i = (left + right) // 2          # nums1 左半边的元素个数
            j = half - i                     # nums2 左半边的元素个数，使两边总数为 half

            # 5. 取四个关键边界值，使用哨兵 -inf / +inf 处理越界
            A_left  = float('-inf') if i == 0 else nums1[i - 1]
            A_right = float('inf')  if i == m else nums1[i]
            B_left  = float('-inf') if j == 0 else nums2[j - 1]
            B_right = float('inf')  if j == n else nums2[j]

            # 6. 检查划分是否合法
            if A_left <= B_right and B_left <= A_right:
                # 正确划分，直接计算中位数
                if (m + n) % 2 == 1:
                    # 奇数长度，左半边最大即为中位数
                    return float(max(A_left, B_left))
                else:
                    # 偶数长度，取左半边最大和右半边最小的平均值
                    return (max(A_left, B_left) + min(A_right, B_right)) / 2.0
            elif A_left > B_right:
                # A 的左半边太大，说明 i 取太大，需要左移
                right = i - 1
            else:
                # B 的左半边太大，说明 i 取太小，需要右移
                left = i + 1

        # 理论上不会到达这里，所有输入都有解
        raise ValueError("Input arrays are not sorted or invalid.")
```

**举例走一遍**（`nums1 = [1,3]`，`nums2 = [2]`）  

1. 初始：`len(nums1)=2`，`len(nums2)=1`，因为 `2 > 1`，交换，使 `nums1=[2]`（`m=1`），`nums2=[1,3]`（`n=2`）。  
2. `half = (1+2+1)//2 = 2`。  
3. `left=0, right=1`。  

| 循环 | i | j | A_left | A_right | B_left | B_right | 判定 | 操作 | left/right |
|------|---|---|--------|---------|--------|----------|------|------|------------|
| 1    | (0+1)//2 = 0 | 2-0 = 2 | -inf | A[0]=2 | B[1]=3 | B_right = +inf (因为 j==n) | `A_left ≤ B_right` (true) 且 `B_left ≤ A_right`? `B_left=3 ≤ A_right=2` false | `B_left > A_right` → left = i+1 = 1 | left=1, right=1 |
| 2    | (1+1)//2 = 1 | 2-1 = 1 | A_left = A[0]=2 | A_right = +inf (i==m) | B_left = B[0]=1 | B_right = B[1]=3 | 检查：2 ≤ 3 && 1 ≤ +inf → true | 找到合法划分 | - |

此时总长度 `3` 为奇数，返回 `max(A_left, B_left) = max(2,1) = 2` → 结果 `2.0`（即原始数组的中位数）。

**复杂度分析**  
- **时间复杂度**：`O(log(min(m, n)))`。二分搜索只在较短数组上进行，每次把搜索区间折半，最多进行 `log₂(min(m,n))` 次比较。  
- **空间复杂度**：`O(1)`。只使用了若干整数变量和常数级的哨兵值，不随输入规模增长而增加额外空间。

## 对比总结  

| 维度 | 解法一：暴力 / 最直觉解 | 解法二：最优解 |
|------|--------------------------|----------------|
| **核心思路** | 完全合并两个有序数组得到完整序列，再取中位数 | 在较短数组上二分寻找划分，使左半边最大 ≤ 右半边最小，直接得到中位数 |
| **时间复杂度** | `O(m + n)`（线性） | `O(log (min(m, n)))`（对数） |
| **空间复杂度** | `O(m + n)`（需要额外数组） | `O(1)`（原地操作） |
| **实现难度** | 简单直观，适合初学者快速写出可运行代码 | 需要理解二分划分的概念和边界处理，稍有难度 |
| **适用场景** | 数据规模不大，或对性能要求不高时 | 数据规模大，或必须满足 `O(log(m+n))` 进阶要求时 |
| **学习收获** | 熟悉数组遍历、双指针合并、如何计算中位数 | 掌握二分搜索的高级应用、利用有序性进行「划分」技巧、处理极端边界的哨兵思想 |

**最重要的收获**：  
- 通过**暴力合并**可以快速验证思路、熟悉题目本身的定义。  
- 通过**二分划分**则展示了「利用已有的有序结构」可以大幅削减不必要的工作量，这也是许多高级算法题的核心技巧——**把问题转化为在有序集合上做二分搜索**，并通过**哨兵**处理边界，从而实现 `O(log n)` 级别的高效解法。掌握这种思路，对后续学习更复杂的搜索、分治、以及「第 k 大」类问题大有裨益。

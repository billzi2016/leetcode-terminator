## 解法一：暴力 / 最直觉解  

**思路**  
把棋盘想成一个 `n × n` 的二维表，逐个格子尝试放皇后。  
1. 从左上角开始遍历每一个格子。  
2. 对每个格子，先判断如果把皇后放在那里，会不会被已经放好的皇后攻击（同一行、同一列或同一对角线）。  
3. 如果安全，就把皇后放进去，继续往后检查剩下的格子。  
4. 当所有 `n` 个皇后都成功放下时，计数器 `ans` 加一，表示找到一种合法布局。  
5. 把皇后撤回（回溯），继续尝试下一个格子。  

这就是最直接的“枚举所有可能，然后筛选合法”的办法，适合刚学编程的同学把概念先弄清楚。

---

**涉及的知识点**  

| 知识点 | 解释（面向零基础） |
|--------|-------------------|
| **嵌套循环** | 在程序里用 `for` 或 `while` 把一件事重复做很多次。这里用两层循环遍历行和列。 |
| **数组 / 列表** | 用一段连续的内存来存放若干个相同类型的值。我们用列表记录每一行皇后所在的列号。 |
| **回溯（Backtracking）** | 当一步走不通时，撤回上一步的选择，尝试别的可能。就像走迷宫时走错路要回头重新找路。 |
| **冲突检测** | 判断两个皇后是否在同一行、列或对角线上。只要满足其中一个，就会相互攻击。 |

---

**逐步拆解**  

1. **初始化**  
   - 创建一个长度为 `n` 的列表 `pos`，`pos[i]` 表示第 `i` 行皇后放在第几列（未放时设为 `-1`）。  
   - 初始化答案计数 `ans = 0`。  

2. **递归函数 `dfs(row)`**（尝试在第 `row` 行放皇后）  
   - **终止条件**：如果 `row == n`，说明已经成功放完所有行，`ans += 1`，返回。  
   - **遍历列**：对 `col` 从 `0` 到 `n-1` 循环。  
   - **冲突检测**：遍历已经放好的行 `i`（`0 ≤ i < row`），检查  
        - 同列：`pos[i] == col`  
        - 主对角线：`pos[i] - i == col - row`  
        - 副对角线：`pos[i] + i == col + row`  
     只要有一条成立，就说明当前位置会被攻击，直接 `continue`（尝试下一个列）。  
   - **放置皇后**：`pos[row] = col`。  
   - **递归进入下一行**：`dfs(row + 1)`。  
   - **回溯**：撤销本行的选择，`pos[row] = -1`（因为后面还会尝试别的列）。  

3. **调用入口**：`dfs(0)`，从第 0 行开始搜索。  

4. **返回答案**：函数结束后返回 `ans`。

---

**代码**  

```python
class Solution:
    def totalNQueens(self, n: int) -> int:
        """
        暴力回溯求解 N 皇后问题的解的个数
        """
        # pos[i] 表示第 i 行皇后所在的列号，-1 表示该行还未放皇后
        pos = [-1] * n
        ans = 0                         # 用来统计合法布局的数量

        def dfs(row: int):
            """尝试在第 row 行放置皇后"""
            nonlocal ans                # 让内部函数能够修改外层的 ans
            if row == n:                # 所有行都已经放完，找到一种解
                ans += 1
                return

            # 逐列尝试放置皇后
            for col in range(n):
                conflict = False       # 标记当前位置是否会冲突
                # 检查已经放好的前 rows 行是否会攻击 (row, col)
                for i in range(row):
                    # 同列冲突
                    if pos[i] == col:
                        conflict = True
                        break
                    # 主对角线冲突：左上↘右下方向，行列差相等
                    if pos[i] - i == col - row:
                        conflict = True
                        break
                    # 副对角线冲突：右上↙左下方向，行列和相等
                    if pos[i] + i == col + row:
                        conflict = True
                        break
                if conflict:            # 若冲突则尝试下一列
                    continue

                # 放置皇后
                pos[row] = col
                # 进入下一行继续搜索
                dfs(row + 1)
                # 回溯：撤销本行的选择，尝试别的列
                pos[row] = -1

        # 从第 0 行开始搜索
        dfs(0)
        return ans
```

**复杂度分析**  

- **时间复杂度**：  
  暴力回溯会尝试每一行的每一列，最坏情况是 `n` 行 `n` 列的全部组合，即 `O(n!)`（因为每放一行可选的列数会逐渐减少）。对 `n ≤ 9` 仍能接受，但随 `n` 增大非常快。  

- **空间复杂度**：  
  只使用了 `pos` 长度为 `n` 的列表以及递归调用栈深度为 `n`，因此 `O(n)` 的额外空间。

## 解法二：最优解（位运算 + 回溯）  

**核心洞察**  
在解法一里，我们每次都要遍历已经放好的行去检查列、主对角线和副对角线是否冲突，这是一种**线性扫描**。  
实际上，棋盘的列、两条对角线都可以用 **位**（二进制）来表示：  
- 第 `i` 列是否已经被占用 → 用一个 `int` 的第 `i` 位标记。  
- 主对角线 (`\`) 的冲突可以用 `row - col` 表示，但它的取值范围是 `[-(n-1), n-1]`，不方便直接做位运算。我们把它平移 `n-1` 后，用 `row - col + n - 1` 作为下标。  
- 副对角线 (`/`) 的冲突用 `row + col` 表示，取值范围 `[0, 2n-2]`。  

用 **位掩码**（mask）记录哪些列、哪些主对角线、哪些副对角线已经被占用，**一次位运算**就能判断当前位置是否安全，省去遍历已放皇后的大循环，从而把时间降低到 `O(n!)` 的常数因子大幅下降，实际运行速度快很多。

---

**涉及的知识点**  

| 知识点 | 解释 |
|--------|------|
| **位运算** | 把整数看成二进制的若干位（0/1），`&`（与）可以判断两位是否同为 1，`|`（或）可以把两位合并为 1，`~`（取反）把 0 变 1，`<<`（左移）把位向左移动相当于乘以 2 的幂。这里用它们快速记录和查询“某列/对角线是否被占”。 |
| **回溯** | 同解法一，只是这次判断是否冲突的方式变成了 O(1) 的位运算。 |
| **整数掩码 (mask)** | 用一个整数的每一位代表一种状态，例如 `columns = 0b0101` 表示第 0、2 列被占用。 |

---

**逐步拆解**  

1. **准备三个整数掩码**  
   - `columns`：第 `i` 位为 1 表示第 `i` 列已有皇后。  
   - `diag1`（左上→右下的主对角线）：第 `i` 位为 1 表示第 `i` 条主对角线被占。下标 = `row - col + n - 1`。  
   - `diag2`（右上→左下的副对角线）：第 `i` 位为 1 表示第 `i` 条副对角线被占。下标 = `row + col`。  

2. **递归函数 `dfs(row, columns, diag1, diag2)`**  
   - **终止条件**：`row == n` → 已经放完所有行，答案 `ans += 1`。  
   - **计算本行所有可放置位置**：  
        ```python
        # 所有 n 列对应的掩码，全部为 1（比如 n=4 => 0b1111）
        all_one = (1 << n) - 1
        # 已被占用的位 = 列占用 | 主对角线占用 | 副对角线占用
        occupied = columns | diag1 | diag2
        # 取反后与 all_one 取交集，得到“空位”掩码
        free = ~occupied & all_one
        ```  
   - **循环取出每一个空位**（用 `lowbit = free & -free` 取最右边的 1）  
        - 把该位对应的列号记为 `col = lowbit.bit_length() - 1`（或 `int(math.log2(lowbit))`）。  
        - **递归进入下一行**，更新三个掩码：  
            - `columns | lowbit`（占用本列）  
            - `(diag1 | lowbit) << 1`（左上→右下对角线向左移动一格）  
            - `(diag2 | lowbit) >> 1`（右上→左下对角线向右移动一格）  
        - **消除已处理的位**：`free ^= lowbit`（把该位设为 0，继续找下一个空位）。  

3. **入口**：`dfs(0, 0, 0, 0)`。  

4. **返回答案**：`ans`。

---

**代码**  

```python
class Solution:
    def totalNQueens(self, n: int) -> int:
        """
        使用位运算的回溯求解 N 皇后问题的解的个数
        关键点：用 3 个整数的二进制位分别记录列、主对角线、副对角线的占用情况
        """
        ans = 0                     # 用来累计合法布局的数量
        all_one = (1 << n) - 1      # n 个低位全为 1 的掩码，例如 n=4 => 0b1111

        def dfs(row: int, columns: int, diag1: int, diag2: int):
            """
            row      : 当前要放皇后的行号
            columns  : 第 i 列是否已被占用（第 i 位为 1 表示占用）
            diag1    : 主对角线 (row - col + n - 1) 是否占用
            diag2    : 副对角线 (row + col) 是否占用
            """
            nonlocal ans
            if row == n:            # 所有行都已成功放置
                ans += 1
                return

            # 1. 计算本行可以放置皇后的位置（用 1 表示空位）
            # 已被占用的位 = 列占用 | 主对角线占用 | 副对角线占用
            occupied = columns | diag1 | diag2
            # 取反后与 all_one 取交集，得到仅在 n 位范围内的“空位”掩码
            free = (~occupied) & all_one

            # 2. 逐个尝试每一个空位
            while free:
                # 取最右边的 1（即当前可以放置的最左侧位置）
                lowbit = free & -free          # 低位的 1，二进制技巧
                # 计算对应的列号（从 0 开始），lowbit 是 2^col
                col = (lowbit.bit_length() - 1)

                # 3. 递归进入下一行，更新三种占用状态
                dfs(
                    row + 1,
                    columns | lowbit,               # 本列被占
                    (diag1 | lowbit) << 1,          # 主对角线向左移动一格
                    (diag2 | lowbit) >> 1           # 副对角线向右移动一格
                )

                # 4. 把已经尝试过的位从 free 中移除，继续循环
                free ^= lowbit   # 等价于 free = free & (free - 1)

        # 从第 0 行开始搜索，初始时所有占用掩码都是 0
        dfs(0, 0, 0, 0)
        return ans
```

**举例走一遍**（`n = 4`）  

| 步骤 | 参数 `(row, columns, diag1, diag2)` | `occupied` (十进制) | `free` (二进制) | 取的 `lowbit` | 递归后新参数 | 说明 |
|------|------------------------------------|---------------------|----------------|--------------|--------------|------|
| 1 | `(0, 0b0000, 0b0000, 0b0000)` | `0` | `~0 & 0b1111 = 0b1111` (所有列可用) | `lowbit = 0b0001` (列0) | `dfs(1, 0b0001, 0b0010, 0b0000)` | 放在第 0 行第 0 列 |
| 2 | `(1, 0b0001, 0b0010, 0b0000)` | `0b0011` | `~0b0011 & 0b1111 = 0b1100` (列2、3) | `lowbit = 0b0100` (列2) | `dfs(2, 0b0101, 0b1010, 0b0010)` | 第 1 行放在列 2 |
| 3 | `(2, 0b0101, 0b1010, 0b0010)` | `0b1111` | `~0b1111 & 0b1111 = 0b0000` | **无** | **回溯** | 第 2 行已无合法位置，回到步骤 2 |
| 2 (回溯) | 仍在 `(1, 0b0001, 0b0010, 0b0000)` | `free` 仍为 `0b1100`，已去掉列2 → `free ^= 0b0100 = 0b1000` | `lowbit = 0b1000` (列3) | `dfs(2, 0b1001, 0b0100, 0b0100)` | 第 1 行改放列 3 |
| 3 | `(2, 0b1001, 0b0100, 0b0100)` | `0b1101` | `~0b1101 & 0b1111 = 0b0010` (仅列1可用) | `lowbit = 0b0010` (列1) | `dfs(3, 0b1011, 0b1000, 0b0010)` | 第 2 行放列 1 |
| 4 | `(3, 0b1011, 0b1000, 0b0010)` | `0b1011 | 0b1000 | 0b0010 = 0b1011` | `~0b1011 & 0b1111 = 0b0100` (列2) | `lowbit = 0b0100` (列2) | `dfs(4, 0b1111, 0b10000, 0b0001)` | 第 3 行放列 2，`row==4` → 找到一种解，`ans=1` |
| **回溯至根** | 继续在根层的 `free` 中去掉列0 → `free = 0b1110` → 取 `lowbit=0b0010` (列1) | … | … | … | … | 同理会得到第二种合法布局，最终 `ans = 2` |

可以看到，**每一次判断是否冲突只用了几次位运算**，而不需要遍历已经放好的行。

---

**复杂度分析**  

- **时间复杂度**：  
  与普通回溯的递归树结构相同，仍是 `O(n!)`（因为每行可选的列数随行数递减）。但每一步的冲突检测从 `O(row)` 降到 `O(1)` 位运算，实际运行时间大约是普通回溯的 **1/10~1/20**（常数因子更小），对 `n ≤ 9` 几乎瞬间完成。  

- **空间复杂度**：  
  只使用了递归栈深度 `n`（`O(n)`）以及 3 个整数的掩码（常数空间），同样是 `O(n)`。

## 对比总结  

| 项目 | 解法一：普通回溯 | 解法二：位运算回溯 |
|------|----------------|-------------------|
| **核心思路** | 逐行遍历、用数组记录已放皇后，线性检查冲突 | 用二进制位记录列、两条对角线的占用，一次位运算即可判断冲突 |
| **时间复杂度** | `O(n!)`（每一步冲突检查 `O(row)`） | `O(n!)`（冲突检查 `O(1)`） |
| **空间复杂度** | `O(n)`（数组 + 递归栈） | `O(n)`（递归栈 + 3 个整数） |
| **实现难度** | 简单直观，适合初学者理解递归与回溯 | 需要掌握位运算技巧，稍微抽象，但代码更简洁高效 |
| **学习收获** | - 理解递归的“尝试‑回溯”过程<br>- 学会如何用数组检测冲突 | - 掌握位掩码的思想，体会**用空间换时间**的技巧<br>- 深入理解回溯的剪枝优化方式 |
| **适用范围** | 小规模 n（如本题 `n ≤ 9`）亦可接受 | 对更大规模的 N‑Queens（如 `n = 14`）或需要极致性能的场景 |

**最重要的收获**：  
无论是普通回溯还是位运算优化，**核心都是“把问题拆成一步步尝试、遇到冲突立即回退”**。掌握了这套思路后，面对大多数组合搜索类问题（如数独、排列组合）都能快速构建出有效的解法；而位运算则是让你的实现更“机器友好”的高级技巧。祝你在算法的道路上越走越远 🚀。

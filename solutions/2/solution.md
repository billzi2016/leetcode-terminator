## 解法一：暴力 / 最直觉解  

**思路**  
把两个链表分别「展开」成普通的整数（因为题目说的数字不会太大，直接用 Python 的大整数就行），把这两个整数相加得到和，再把和「拆」回链表。  
这就像我们平时把「342」写成「3→4→2」一样，只是这里的链表是逆序的，所以展开时要把每一位乘上相应的 10 的幂。

**涉及的知识点**  
1. **链表遍历**：从头结点一直往后走，依次访问每个节点的 `val`。这相当于顺序读取数组，只不过这里的容器是指针相连的。  
2. **整数拼接**：把遍历得到的每个数字按位累加到一个变量里，用 `num += digit * (10 ** position)`。这里的 `position` 表示当前是第几位（从 0 开始）。  
3. **整数转链表**：把得到的整数逐位取模 `% 10`，生成新的节点并链接起来。取模得到最低位，除以 10 去掉已经取出的位。

**逐步拆解**  
1. **遍历 `l1`**：从头到尾，把每个节点的值乘以对应的 10 的幂累加到 `num1`。  
2. **遍历 `l2`**：同上，得到 `num2`。  
3. **相加**：`total = num1 + num2`。  
4. **构造结果链表**：如果 `total` 为 0，直接返回只有一个 `0` 的链表。否则循环 `total > 0`：  
   - 取 `digit = total % 10`（当前最低位）。  
   - 创建新节点 `ListNode(digit)`，挂到结果链表后面。  
   - `total //= 10`（去掉已经取出的最低位）。  
5. 返回结果链表的头节点。

**代码**  

```python
# Definition for singly-linked list.
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val          # 当前节点保存的数字
        self.next = next        # 指向下一个节点的指针

class Solution:
    def addTwoNumbers(self, l1: ListNode, l2: ListNode) -> ListNode:
        # ---------- 1. 把链表 l1 转成整数 ----------
        num1 = 0          # 用来累加 l1 对应的整数
        mul = 1           # 当前位对应的 10 的幂，起始为 10^0 = 1
        while l1:         # 当链表没有遍历完时
            num1 += l1.val * mul   # 把当前位的数字加入到整数中
            mul *= 10               # 下一位乘以 10
            l1 = l1.next            # 移动到下一个节点

        # ---------- 2. 把链表 l2 转成整数 ----------
        num2 = 0
        mul = 1
        while l2:
            num2 += l2.val * mul
            mul *= 10
            l2 = l2.next

        # ---------- 3. 求和 ----------
        total = num1 + num2

        # ---------- 4. 把和拆回链表 ----------
        # 如果 total 为 0，直接返回一个只有 0 的节点
        if total == 0:
            return ListNode(0)

        dummy_head = ListNode(0)   # 哑结点，帮助我们简化链表构造
        cur = dummy_head           # cur 用来指向当前要添加新节点的位置
        while total > 0:
            digit = total % 10     # 取最低位
            cur.next = ListNode(digit)   # 创建新节点并接在后面
            cur = cur.next                 # cur 前进到新节点
            total //= 10                # 去掉已经取出的位

        return dummy_head.next   # 哑结点的下一个才是答案链表的头
```

**举例走一遍**（示例 1：`l1 = [2,4,3]`, `l2 = [5,6,4]`）  

| 步骤 | 变量 | 说明 |
|------|------|------|
| 1️⃣遍历 `l1` | `num1 = 0, mul = 1` → 读取 `2` → `num1 = 2*1 = 2`，`mul = 10`<br>读取 `4` → `num1 = 2 + 4*10 = 42`，`mul = 100`<br>读取 `3` → `num1 = 42 + 3*100 = 342` | 得到整数 342 |
| 2️⃣遍历 `l2` | 同理得到 `num2 = 465` | |
| 3️⃣求和 | `total = 342 + 465 = 807` | |
| 4️⃣拆回链表 | `total = 807`<br>① `digit = 807 % 10 = 7` → 新节点 `7`<br>`total = 80`<br>② `digit = 80 % 10 = 0` → 新节点 `0`<br>`total = 8`<br>③ `digit = 8 % 10 = 8` → 新节点 `8`<br>`total = 0` 结束 | 结果链表为 `7 → 0 → 8`，即 `[7,0,8]` |

**复杂度分析**  
- **时间复杂度**：`O(m + n)`，其中 `m`、`n` 分别是两条链表的长度。我们分别遍历两条链表一次，再遍历一次生成结果链表。  
- **空间复杂度**：`O(1)`（不计返回的结果链表）。只用了几个整型变量 `num1、num2、total、mul`，与输入规模无关。

## 解法二：最优解  

**核心洞察**  
把「把链表转成整数」这一步去掉，直接在遍历链表的过程中就完成「按位相加并携带进位」的操作。因为每个节点只保存一位数字，直接把对应位相加得到当前位的结果和进位，省去了大整数的构造与拆解，既省空间又省时间。

**涉及的知识点**  
1. **链表同步遍历**：同时移动 `l1`、`l2` 两个指针，像两条小船并排划桨，保证每一次循环处理同一位的数字。  
2. **进位（carry）概念**：在十进制加法中，如果某位的和 ≥ 10，需要把「十」留下给更高位，这个「十」叫进位。我们用一个变量 `carry` 保存上一次循环产生的进位，下一次循环再加进去。  
3. **哑结点（dummy head）**：为了让链表的构造代码更简洁，提前创建一个值不重要的节点作为头部，所有真正的结果节点都挂在它后面，最后返回 `dummy.next` 即可。

**逐步拆解**  
1. **初始化**：创建 `dummy = ListNode(0)`，`curr = dummy` 指向当前要插入新节点的位置；`carry = 0`。  
2. **循环条件**：只要 `l1`、`l2` 任意还有节点 **或** `carry` 不为 0，就继续。  
3. **取当前位的数值**：`x = l1.val if l1 else 0`，`y = l2.val if l2 else 0`。如果对应链表已经遍历完，用 0 填充。  
4. **计算本位和以及新进位**：`total = x + y + carry`；`carry = total // 10`（得到进位 0 或 1）；`digit = total % 10`（本位的实际数字）。  
5. **生成新节点并挂到结果链表**：`curr.next = ListNode(digit)`，`curr = curr.next`。  
6. **指针前进**：如果 `l1` 还未结束，`l1 = l1.next`；同理 `l2 = l2.next`。  
7. **循环结束**后，`dummy.next` 即为答案链表的头。

**代码**  

```python
# Definition for singly-linked list.
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def addTwoNumbers(self, l1: ListNode, l2: ListNode) -> ListNode:
        dummy = ListNode(0)      # 哑结点，帮助我们统一处理头结点
        curr = dummy             # curr 始终指向结果链表的最后一个节点
        carry = 0                # 进位，初始为 0

        # 同时遍历两条链表，只要还有未处理的节点或还有进位就继续
        while l1 or l2 or carry:
            # 取当前位的数字，如果对应链表已经结束则用 0 替代
            x = l1.val if l1 else 0
            y = l2.val if l2 else 0

            # 本位相加再加上上一轮的进位
            total = x + y + carry

            # 计算新的进位（total // 10）和当前位的数字（total % 10）
            carry = total // 10
            digit = total % 10

            # 把当前位的数字生成新节点并接到结果链表后面
            curr.next = ListNode(digit)
            curr = curr.next   # curr 前进到新节点，准备下一轮插入

            # 链表指针前进（如果还有的话）
            if l1:
                l1 = l1.next
            if l2:
                l2 = l2.next

        # 返回哑结点的下一个节点，即真正的结果链表头
        return dummy.next
```

**举例走一遍**（示例 1：`l1 = [2,4,3]`, `l2 = [5,6,4]`）  

| 循环 | l1.val | l2.val | carry 进位 (上一步) | total = x+y+carry | 新 carry | digit (本位) | 结果链表状态 |
|------|--------|--------|-------------------|-------------------|----------|--------------|--------------|
| 1    | 2      | 5      | 0                 | 2+5+0 = 7         | 0        | 7            | `7` |
| 2    | 4      | 6      | 0                 | 4+6+0 = 10        | 1        | 0            | `7 → 0` |
| 3    | 3      | 4      | 1                 | 3+4+1 = 8         | 0        | 8            | `7 → 0 → 8` |
| 4    | None   | None   | 0                 | 循环结束条件不满足 | —        | —            | 结束，返回 `7 → 0 → 8` |

**复杂度分析**  
- **时间复杂度**：`O(max(m, n))`，只遍历两条链表一次，`m`、`n` 为两条链表的长度。  
- **空间复杂度**：`O(1)`（不计返回的结果链表）。只用了常数个指针和整数变量 `carry`、`total`、`digit`。

## 对比总结  

| 项目 | 解法一（转整数） | 解法二（位加） |
|------|----------------|----------------|
| **核心思路** | 先把链表转换为普通整数再相加，最后再转回链表 | 同时遍历两条链表，逐位相加并携带进位 |
| **时间复杂度** | `O(m + n)`（两次遍历 + 一次生成） | `O(max(m, n))`（仅一次同步遍历） |
| **额外空间** | `O(1)`（仅几个整型变量） | `O(1)`（同上） |
| **代码难度** | 直观、易懂，但依赖大整数，概念上多了「转换」两步 | 更符合手算过程，代码更简洁、一步到位 |
| **适用场景** | 初学者想先把问题抽象为「整数相加」时 | 面试或正式环境推荐的标准做法 |
| **学习收获** | 理解链表遍历、整数构造/拆解的基本技巧 | 掌握 **进位** 思想、**哑结点** 用法以及**同步遍历**技巧 |

> **最重要的收获**：在处理链表数字相加这类题目时，核心是「逐位相加 + 进位」的思想。只要把进位抽象成一个变量，并在每一步更新，就可以在 **O(1) 额外空间**、**一次遍历**内完成任务，这也是大多数链表题目的通用模板。学习并熟练运用哑结点、同步遍历以及进位处理，将帮助你快速攻克类似的链表运算问题。

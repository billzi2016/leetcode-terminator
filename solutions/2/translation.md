## 题目描述

给定两个非空链表，分别表示两个非负整数。数字以逆序方式存储，并且每个节点只包含一个数字。请将这两个数相加，并以链表形式返回它们的和。可以假设这两个数除 0 本身外，都不含任何前导零。

## 示例

**示例 1：**
```
Input: l1 = [2,4,3], l2 = [5,6,4]
Output: [7,0,8]
Explanation: 342 + 465 = 807.
```

**示例 2：**
```
Input: l1 = [0], l2 = [0]
Output: [0]
```

**示例 3：**
```
Input: l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]
Output: [8,9,9,9,0,0,0,1]
```

## 约束条件

- 每个链表的节点数范围为 `[1, 100]`。
- `0 <= Node.val <= 9`
- 保证链表表示的数字没有前导零。

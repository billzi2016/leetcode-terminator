## 题目描述

给定一个整数数组 `nums` 和一个整数 `k`，请在数组中找出满足 **`nums[j] - nums[i] = k`**（`i != j`）的两个下标 `i` 与 `j`，并返回这两个下标组成的数组 `[i, j]`。  

假设数组中恰好只有唯一的一组满足条件的下标对，且同一个元素不能被重复使用。返回的下标顺序不限。

## 输入输出格式

**输入**

- 第一行一个整数 `n`，表示数组 `nums` 的长度。
- 第二行 `n` 个整数，表示数组 `nums` 的元素，元素之间用空格分隔。
- 第三行一个整数 `k`，表示目标差值。

**输出**

- 一行包含两个整数 `i` 与 `j`（`0 ≤ i, j < n`），用空格分隔，表示满足 `nums[j] - nums[i] = k` 的下标。

## 示例

### 示例 1
```
输入：
4
2 7 11 15
5
输出：
0 1
解释：nums[1] - nums[0] = 7 - 2 = 5，满足条件。
```

### 示例 2
```
输入：
3
3 2 4
2
输出：
1 2
解释：nums[2] - nums[1] = 4 - 2 = 2，满足条件。
```

### 示例 3
```
输入：
2
3 3
0
输出：
0 1
解释：nums[1] - nums[0] = 3 - 3 = 0，满足条件。
```

## 约束条件

- `2 ≤ n ≤ 10^4`
- `-10^9 ≤ nums[i] ≤ 10^9`
- `-10^9 ≤ k ≤ 10^9`
- 题目保证恰好存在唯一的一组满足条件的下标 `(i, j)`。

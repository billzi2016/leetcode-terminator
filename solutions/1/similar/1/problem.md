## 题目描述

给定一个整数数组 `nums` 和一个整数 `target`，请统计满足以下条件的 **不同数值对** 的数量：

- 选取数组中的两个下标 `i` 与 `j`（`i ≠ j`），使得 `nums[i] + nums[j] = target`；
- 对于数值对 `(a, b)` 与 `(b, a)` 视为同一对；
- 如果 `a = b`，则要求数组中该数值出现至少两次。

返回满足条件的不同数值对的总数。

---

## 输入输出格式

**输入格式**

```
n
nums[0] nums[1] ... nums[n-1]
target
```

- 第一行一个整数 `n`，表示数组长度；
- 第二行包含 `n` 个用空格分隔的整数，表示数组 `nums`；
- 第三行一个整数 `target`。

**输出格式**

```
count
```

- 输出一个整数 `count`，表示满足条件的不同数值对的数量。

---

## 示例

**示例 1**

```
输入：
5
1 5 7 -1 5
6

输出：
2
```

解释：满足条件的不同数值对为 `(1,5)` 与 `(-1,7)`，共 2 对。

---

**示例 2**

```
输入：
4
2 2 2 2
4

输出：
1
```

解释：唯一的数值对为 `(2,2)`，因为数组中 2 至少出现两次。

---

**示例 3**

```
输入：
3
1 2 3
7

输出：
0
```

解释：不存在任意两个数之和等于 7 的数值对。

---

## 约束条件

- `2 ≤ n ≤ 10^5`
- `-10^9 ≤ nums[i] ≤ 10^9`
- `-10^9 ≤ target ≤ 10^9`
- 结果可能很大，请使用 64 位整数类型（如 `long long`）存储。

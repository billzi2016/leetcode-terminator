## 思路分析
要统计满足 `nums[i] + nums[j] = target` 的 **不同数值对**，关键在于：

1. **去重**  
   对于数值对 `(a, b)` 与 `(b, a)` 只算一次，等价于只统计 unordered pair `{a,b}`。

2. **出现次数的限制**  
   - 当 `a != b` 时，只要数组中分别出现过 `a` 与 `b` 即可。  
   - 当 `a == b` 时，需要该数值在数组中出现 **至少两次**，否则不构成合法的下标对。

基于上述要求，最直接的做法是先统计每个数值出现的次数（哈希表 `cnt`），随后遍历哈希表的键：

- 设 `x` 为当前遍历的键，`y = target - x` 为与之配对的数值。  
- 若 `y` 不在 `cnt` 中，显然不存在配对。  
- 为避免重复计数，只在 `x < y` 时计数一次（对应 unordered pair）。  
- 当 `x == y`（即 `2*x == target`）时，检查 `cnt[x] >= 2`，满足条件则计数一次。

遍历完所有键后得到的计数即为答案。

**注意**  
- 哈希表的键数量至多为 `n`，遍历一次即可完成统计，时间复杂度为 `O(n)`。  
- 使用 Python 的 `int`（内部为大整数）即可满足 64 位整数需求。

## 代码实现

```python
import sys
from collections import Counter

def main() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    nums = [int(next(it)) for _ in range(n)]
    target = int(next(it))

    cnt = Counter(nums)          # 统计每个数值出现次数
    visited = set()              # 已经处理过的数值，防止重复计数
    ans = 0

    for x in cnt:
        y = target - x
        if y not in cnt:
            continue

        # 为保证每个 unordered pair 只计一次，只在 x <= y 时考虑
        if x < y:
            ans += 1
        elif x == y:
            # 需要同一个数出现至少两次
            if cnt[x] >= 2:
                ans += 1
        # x > y 的情况已经在 (y, x) 时处理过，无需再计

    print(ans)

if __name__ == "__main__":
    main()
```

## 复杂度分析
- **时间复杂度**：`O(n)`  
  - 构建计数哈希表 `Counter(nums)` 需要遍历一次数组 `O(n)`。  
  - 随后遍历哈希表的键，键的数量至多为 `n`，每次操作均为 `O(1)`。  

- **空间复杂度**：`O(m)`，其中 `m` 为不同数值的个数，最坏情况 `m = n`（全部元素互不相同），即额外使用 `O(n)` 的哈希表存储计数。

## 心得
这道题的核心是 **去重** 与 **出现次数的判断**。  
- 若直接在原数组上使用双指针或暴力枚举，很难兼顾去重且会超出时间限制。  
- 通过先统计频次，再基于数值本身进行配对，能够一次遍历完成所有判断，既简洁又高效。  
- 关键的细节是 **只在 `x <= y`（或 `x < y`）时计数**，这样自然避免了 `(a,b)` 与 `(b,a)` 的重复统计。  
- 对于 `x == y` 的特殊情况，只要检查频次是否 ≥2，即可满足 “同一数值出现至少两次” 的要求。  

整体思路在实际面试或竞赛中非常常见，掌握后可以轻松迁移到类似 “求不同数对满足某种关系” 的题目。

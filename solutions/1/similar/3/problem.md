## 题目描述

给定一个整数数组 `nums` 和一个整数 `target`，请在数组中找出 **恰好两个** 不同下标 `i` 与 `j`（`i != j`），使得  

```
nums[i] - nums[j] = target
```

返回这两个下标 `[i, j]`（下标从 **0** 开始计数）。如果存在多组满足条件的下标，返回任意一组即可。可以保证 **至少有唯一一组** 满足条件的答案。

---

## 输入输出格式

**输入**

- 第一行包含两个整数 `n` 和 `target`，分别表示数组长度和目标差值。  
- 第二行包含 `n` 个整数，表示数组 `nums` 的元素，元素之间以空格分隔。

**输出**

- 输出一行，包含两个整数 `i` 与 `j`，用空格分隔，表示满足 `nums[i] - nums[j] = target` 的下标。

---

## 示例

### 示例 1

**输入**
```
4 5
2 7 11 15
```

**输出**
```
1 0
```

**解释**  
`nums[1] - nums[0] = 7 - 2 = 5 = target`，因此返回下标 `[1, 0]`。

---

### 示例 2

**输入**
```
3 -2
3 2 4
```

**输出**
```
1 2
```

**解释**  
`nums[1] - nums[2] = 2 - 4 = -2 = target`，返回下标 `[1, 2]`。

---

### 示例 3

**输入**
```
2 0
3 3
```

**输出**
```
0 1
```

**解释**  
`nums[0] - nums[1] = 3 - 3 = 0 = target`，返回下标 `[0, 1]`。

---

## 约束条件

- `2 <= n <= 10^4`
- `-10^9 <= nums[i] <= 10^9`
- `-10^9 <= target <= 10^9`
- 题目保证 **恰好只有一组** 满足条件的下标对。

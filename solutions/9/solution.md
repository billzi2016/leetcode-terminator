## 解法一：暴力 / 最直觉解

**思路**  
把整数当成一串字符来处理。先把整数 `x` 转成字符串 `s`，再把 `s` 翻转得到 `rev`，如果 `s` 和 `rev` 完全相同，就说明这个数正着读和倒着读是一样的，即回文。对于没有学过算法的同学，这种“把数字变成文字，再比较文字”的方法是最直观、最容易想到的。

**涉及的知识点**  
- **字符串**：在编程里，字符串是一串字符（比如 `"123"`），可以像数组一样一个字符一个字符地访问。  
- **字符串切片**：`s[::-1]` 表示把字符串 `s` 从后往前读，得到一个新的倒序字符串。切片是 Python 提供的快速取子串的语法。  
- **比较运算**：`==` 用来判断两个值是否相等，这里用来比较原字符串和倒序字符串是否完全相同。

**逐步拆解**  
1. **判断负数**：如果 `x` 小于 0，直接返回 `False`（负号会让倒序后不相等）。  
2. **整数转字符串**：使用 `str(x)` 把整数变成字符串 `s`。  
3. **得到倒序字符串**：`s[::-1]` 把 `s` 逆序得到 `rev`。  
4. **比较**：如果 `s` 与 `rev` 完全相同，说明是回文，返回 `True`；否则返回 `False`。  

**代码**

```python
def isPalindrome(x: int) -> bool:
    # 1. 负数直接不是回文，因为会出现 '-' 符号
    if x < 0:
        return False

    # 2. 把整数转换成字符串，例如 121 -> "121"
    s = str(x)

    # 3. 使用切片把字符串倒过来，例如 "121"[::-1] -> "121"
    rev = s[::-1]

    # 4. 比较原字符串和倒序字符串是否相等
    return s == rev
```

**举例走一遍**（示例 1：`x = 121`）

| 步骤 | 变量/操作 | 变量值 | 说明 |
|------|-----------|--------|------|
| 1 | `x < 0?` | `False` | 121 不是负数，继续 |
| 2 | `s = str(x)` | `"121"` | 把整数 121 转成字符串 |
| 3 | `rev = s[::-1]` | `"121"` | 把 `"121"` 逆序，仍是 `"121"` |
| 4 | `s == rev?` | `True` | 两个字符串相同，返回 `True` |

**复杂度分析**  
- **时间复杂度**：`O(n)`，其中 `n` 是整数的位数。我们遍历了一遍字符串（创建倒序字符串也需要遍历）。  
- **空间复杂度**：`O(n)`，因为要额外存储字符串 `s` 和倒序字符串 `rev`，它们的长度都是 `n`。

## 解法二：最优解

**核心洞察**  
直接把整个整数翻转会有整数溢出风险，而且我们其实只需要比较数字的一半即可。观察回文数的特性：**左半边和右半边是镜像的**。因此，只要把右半边数字逐位取出并构成一个新数 `revHalf`，当 `revHalf` 的位数不小于原数的左半边时，就可以停止。此时如果左半边（`x`）等于 `revHalf`（偶数位数）或等于 `revHalf // 10`（奇数位数，去掉中间的那位），就说明是回文。这样只用 **常数额外空间**，而且不需要把整数转成字符串。

**涉及的知识点**  
- **取模 `%`**：`x % 10` 可以得到整数 `x` 最右边的那一位。想象把数字放在纸上，取模就像把纸折叠，只留下最右边的数字。  
- **整除 `//`**：`x // 10` 把整数 `x` 删除最右边的一位。相当于把纸往左“滑动”，最右边的数字被“剪掉”。  
- **循环**：`while` 循环会重复执行代码块，直到条件不满足。这里用来不断把右边的数字搬到 `revHalf` 中。  
- **整数溢出**：在某些语言里，翻转整个整数可能超过数据类型的最大值。我们只翻转一半，避免了这个风险。  

**逐步拆解**  
1. **排除特殊情况**：  
   - 如果 `x` 为负数，直接返回 `False`（负号破坏回文）。  
   - 如果 `x` 不是 0 且末位是 0（即 `x % 10 == 0`），返回 `False`（例如 10，倒过来会变成 01，显然不是回文）。  
2. **初始化 `revHalf = 0`**：用于存放已经翻转好的右半边数字。  
3. **循环取出右半边**：当 `x > revHalf` 时，执行以下操作：  
   - `revHalf = revHalf * 10 + x % 10`：把 `revHalf` 左移一位并加入当前最右位数字。  
   - `x //= 10`：把原数 `x` 去掉最右位。  
   循环结束后，`revHalf` 包含了原数的右半边（可能多了一位中间位）。  
4. **比较**：  
   - 对于偶数位数的回文数：`x == revHalf`。  
   - 对于奇数位数的回文数：中间那一位不影响回文，去掉它后比较：`x == revHalf // 10`。  
   任意一种相等即返回 `True`，否则返回 `False`。  

**代码**

```python
def isPalindrome(x: int) -> bool:
    # 1. 负数不是回文；末位是 0 的非零数也不是回文（比如 10）
    if x < 0 or (x % 10 == 0 and x != 0):
        return False

    revHalf = 0  # 用来保存翻转后的右半边

    # 2. 把右半边数字逐位取出并构成 revHalf，直到 revHalf >= x
    while x > revHalf:
        # 取出当前最右边的数字 (x % 10) 并加入 revHalf 的末尾
        revHalf = revHalf * 10 + x % 10
        # 去掉 x 的最右边数字，为下一次循环做准备
        x //= 10

    # 3. 当数字位数为偶数时，x 与 revHalf 应该相等
    #    当数字位数为奇数时，revHalf 会多出中间的那一位，去掉即可比较
    return x == revHalf or x == revHalf // 10
```

**举例走一遍**（示例 1：`x = 121`）

| 步骤 | 操作 | `x`（左半边） | `revHalf`（右半边） | 说明 |
|------|------|--------------|-------------------|------|
| 初始 | `if` 检查 | 121 | 0 | 不是负数，末位不是 0，继续 |
| 循环 1 | `revHalf = revHalf * 10 + x % 10` → `0*10 + 1 = 1`<br>`x //= 10` → `12` | 12 | 1 | 取出最右位 `1`，放进 `revHalf` |
| 循环 2 | `revHalf = 1*10 + 12 % 10 = 12`<br>`x //= 10` → `1` | 1 | 12 | 再取出下一位 `2`，放进 `revHalf` |
| 循环结束 | 条件 `x > revHalf` 为 `1 > 12` 为 False，退出循环 | 1 | 12 | 现在 `revHalf` 包含了右半边 `12`（多了中间的 `2`） |
| 比较 | `x == revHalf` → `1 == 12` 为 False<br>`x == revHalf // 10` → `1 == 1` 为 True | 1 | 12 | 由于是奇数位数，去掉 `revHalf` 的最后一位（`12 // 10 = 1`），与 `x` 相等，返回 True |

**复杂度分析**  
- **时间复杂度**：`O(log10 n)`，因为每次循环把 `x` 右边的一位数字去掉，循环次数约为数字位数的一半。  
- **空间复杂度**：`O(1)`，只使用了几个整数变量，没有额外的数组或字符串。

## 对比总结

| 项目 | 解法一（字符串） | 解法二（数学翻转） |
|------|-------------------|--------------------|
| **核心思路** | 把数字当成字符串，直接比较正序和倒序 | 只翻转数字的一半，利用数学运算比较左右两边 |
| **时间复杂度** | `O(n)`（n 为位数） | `O(log10 n)`（约等于 `O(n)` 的常数因子更小） |
| **空间复杂度** | `O(n)`（需要存储字符串） | `O(1)`（只用常数个整数） |
| **实现难度** | 低，适合完全没有算法经验的初学者 | 中等，需要理解取模、整除和循环的配合 |
| **关键收获** | 学会字符串的基本操作（转换、切片、比较） | 掌握数位操作技巧，了解如何在不使用额外空间的情况下判断回文，并避免整数溢出 |

> **最重要的收获**：回文判断既可以用直观的“把数字变文字”方式实现，也可以用更高效的“数位翻转”技巧来优化。掌握这两种思路后，你能在不同场景下灵活选取合适的解法，同时对整数的位操作有更深入的认识。

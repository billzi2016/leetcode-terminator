## 题目描述

给定一个非负整数 `x`，判断其二进制表示（不含前导零）是否是回文字符串。如果是，返回 `true`；否则返回 `false`。要求 **不使用** 将整数转换为字符串的方式实现，需通过位运算或数学方法完成判断。

---

## 输入输出格式

**输入**  
- 一行包含一个整数 `x`。

**输出**  
- 如果 `x` 的二进制表示是回文，输出 `true`；否则输出 `false`。

---

## 示例

### 示例 1
**输入**  
```
9
```
**输出**  
```
true
```
**解释**  
`9` 的二进制为 `1001`，正向和反向相同。

### 示例 2
**输入**  
```
10
```
**输出**  
```
false
```
**解释**  
`10` 的二进制为 `1010`，反转后为 `0101`，不相同。

### 示例 3
**输入**  
```
0
```
**输出**  
```
true
```
**解释**  
`0` 的二进制为 `0`，本身即为回文。

---

## 约束条件

- `0 ≤ x ≤ 2³¹ - 1`（即 32 位有符号整数的非负范围）。

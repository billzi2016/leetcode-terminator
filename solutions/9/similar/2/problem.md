## 题目描述

给定一个非负整数 `x`，请判断其二进制表示（不含前导零）是否是回文字符串。如果是，返回 `true`；否则返回 `false`。

* 示例  
  - `x = 9`，二进制为 `1001`，正读和反读相同，返回 `true`。  
  - `x = 10`，二进制为 `1010`，不是回文，返回 `false`。  
  - `x = 0`，二进制为 `0`，是回文，返回 `true`。

## 输入输出格式

**输入**  
一行，一个整数 `x`。

**输出**  
如果 `x` 的二进制表示是回文，输出 `true`（不含引号）；否则输出 `false`。

## 示例

**示例 1**  
```
输入
9
输出
true
```

**示例 2**  
```
输入
10
输出
false
```

**示例 3**  
```
输入
0
输出
true
```

## 约束条件

- `0 ≤ x ≤ 2^31 - 1`  
- 要求时间复杂度为 `O(log x)`，额外空间复杂度为 `O(1)`。

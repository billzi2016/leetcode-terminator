## 解法一：暴力 / 最直觉解  

### **思路**  
把数独看成 9×9 的格子，每个空格子（用 `'.'` 表示）都可以尝试填入 `'1'~'9'` 中的任意一个数字。  
最直观的办法就是 **遍历** 所有空格子，对每个空格子 **逐个尝试** 1~9，检查填进去后是否满足数独的三条规则（行、列、3×3 小宫格不重复）。  
如果合法，就把这个数字写进去，继续递归处理下一个空格子；如果后面出现冲突，就 **回溯**（把刚才写的数字恢复为 `'.'`），尝试下一个数字。  
因为题目保证唯一解，这样的“暴力搜索 + 回溯”一定能找到答案。  

### **涉及的知识点**  
| 知识点 | 解释（面向零基础） |
|--------|--------------------|
| **嵌套循环** | 在 Python 中 `for i in range(9):` 这种写法会一次遍历 0~8，配合两个层次的循环可以一次遍历所有格子（行、列）。 |
| **递归** | 一个函数在自己的内部再次调用自己。这里用递归来处理“填完当前空格后，去填下一个空格”。递归会一直往下走，直到所有空格都被填满。 |
| **回溯** | 当递归发现当前的选择导致后面无法继续时，撤销（恢复）刚才的选择，然后尝试别的可能。相当于在走迷宫时走错路后回头再选另一条路。 |
| **检查合法性** | 用三个 `for` 循环检查同一行、同一列、同一 3×3 小宫格里是否已经出现了相同的数字。 |

### **逐步拆解**  

1. **寻找第一个空格**  
   - 从左上角 (0,0) 开始，顺序扫描每一行每一列，找到 `board[i][j] == '.'` 的位置。  
2. **尝试填入 1~9**  
   - 对于找到的空格，依次尝试数字 `'1'`、`'2'` … `'9'`。  
3. **合法性检查**  
   - 检查当前行 `i`、当前列 `j`、以及所在的 3×3 小宫格（`box_row = i//3*3`、`box_col = j//3*3`）是否已经有相同的数字。  
   - 如果有冲突，直接尝试下一个数字。  
4. **写入数字并递归**  
   - 把合法的数字写入 `board[i][j]`，然后 **递归** 调用同样的搜索函数，继续寻找下一个空格。  
5. **回溯**  
   - 如果递归返回 `False`（说明后面走不通），把 `board[i][j]` 再改回 `'.'`，继续尝试下一个数字。  
6. **结束条件**  
   - 当遍历完所有格子都没有发现 `'.'`，说明已经填满，返回 `True` 表示成功。  

### **代码**  

```python
from typing import List

class Solution:
    def solveSudoku(self, board: List[List[str]]) -> None:
        """
        直接在 board 上修改，使其成为合法的数独解。这里使用最直观的
        “遍历所有空格 + 递归尝试 + 回溯” 的暴力解法。
        """

        def is_valid(r: int, c: int, ch: str) -> bool:
            """
            检查在 (r, c) 位置放字符 ch 是否会违反数独规则。
            1. 同一行不能重复
            2. 同一列不能重复
            3. 同一个 3x3 小宫格不能重复
            """
            for i in range(9):
                # 检查行
                if board[r][i] == ch:
                    return False
                # 检查列
                if board[i][c] == ch:
                    return False
                # 检查 3x3 小宫格
                # 小宫格左上角坐标为 (box_row, box_col)
                box_row = (r // 3) * 3 + i // 3
                box_col = (c // 3) * 3 + i % 3
                if board[box_row][box_col] == ch:
                    return False
            return True

        def backtrack() -> bool:
            """
            递归搜索：找到下一个空格，尝试填数，若全部成功返回 True。
            """
            for row in range(9):
                for col in range(9):
                    if board[row][col] == '.':                # ① 找到空格
                        for digit in map(str, range(1, 10)):  # ② 依次尝试 1~9
                            if is_valid(row, col, digit):    # ③ 合法性检查
                                board[row][col] = digit       # ④ 写入数字
                                if backtrack():               # ⑤ 递归继续
                                    return True               # 找到完整解，直接返回
                                board[row][col] = '.'         # ⑥ 回溯：撤销
                        return False   # 所有数字都不行，返回 False 回到上层
            # 没有空格了，说明已经填满
            return True

        backtrack()   # 启动递归搜索
```

如果在某一步所有 1~9 都不合法，代码会执行第 6 步的 `return False`，把上一层已经写入的数字恢复为 `'.'`（回溯），再尝试下一个候选数字。这样“试错 + 撤销”会遍历所有可能，最终找到唯一合法解。

### **复杂度分析**  

- **时间复杂度**  
  - 最坏情况下，空格数为 81，每个空格都尝试 9 次，且每次合法性检查需要遍历 9 行 + 9 列 + 9 小宫格 → `O(9)` 常数。  
  - 粗略的上界是 `O(9^(81))`（指数级），因为是完整的深度优先搜索。实际因为数独约束非常强，剪枝效果显著，运行时间在几毫秒到几百毫秒之间。  

- **空间复杂度**  
  - 递归深度最多为空格数 ≤ 81，使用的栈空间 `O(81)`（可以视作 `O(1)` 因为上限固定）。  
  - 额外数据结构只有几个局部变量，整体 **O(1)**（不计输入本身）。

## 解法二：最优解  

### **核心洞察**  
暴力解法的慢点在于每次检查合法性都要遍历整行、整列和整宫格，导致大量重复工作。  
**观察**：数独的每一行、每一列、每一个 3×3 小宫格里出现的数字集合是可以**提前记录**的。  
如果我们用 **位掩码（bitmask）** 或 **集合（set）** 来实时维护“已经出现了哪些数字”，则判断一个数字是否可放只需要 **O(1)** 的查表操作，而不必每次遍历 27 次。  
因此，**把三类约束分别用 9 个集合/位掩码保存**，在递归时直接查询/更新这些集合，就可以大幅降低搜索过程的常数因子，使搜索更快。

### **涉及的知识点**  

| 知识点 | 解释（面向零基础） |
|--------|--------------------|
| **集合（set）** | Python 中的 `set` 是一种“无序且不重复”的容器，内部实现为哈希表。`x in s` 判断元素是否在集合里，时间是常数级（非常快）。这里用它来记录某行、某列、某宫格已经出现了哪些数字。 |
| **位掩码（bitmask）**（可选） | 用一个整数的二进制位来表示 1~9 是否已经出现。例如 `mask = 0b001010100` 的第 3 位为 1 表示数字 3 已经在对应行/列/宫格出现。检查/设置某位也只需要位运算，速度极快。 |
| **回溯 + 前向剪枝** | 仍然是递归搜索，但因为我们能 **瞬间** 判断“这个数字是否合法”，所以在搜索树的每一步都能更早地发现冲突（前向剪枝），减少无效的递归调用。 |

### **逐步拆解**  

1. **初始化约束集合**  
   - `rows[9]`、`cols[9]`、`boxes[9]` 各是 `set()`，分别记录第 i 行、第 j 列和第 k 个 3×3 小宫格已经使用的数字。  
   - 扫描整个 board，把已有的数字加入对应的集合。  

2. **递归搜索（DFS）**  
   - 预先把所有空格的坐标收集到 `empties` 列表中，按 **出现次数最少的候选数字**（可选的启发式）排序，以加速。  
   - 对 `empties[pos]`（第 pos 个空格）尝试填入 `1~9` 中 **不在对应行、列、宫格集合** 的数字。  

3. **合法性检查（O(1)）**  
   - 只要 `digit not in rows[r] and digit not in cols[c] and digit not in boxes[b]` 就合法。  

4. **写入并更新集合**  
   - 把数字写入 `board[r][c]`，并把 `digit` 加入 `rows[r]、cols[c]、boxes[b]`。  

5. **递归进入下一空格**  
   - `if dfs(pos + 1): return True` 表示后续全部成功，直接返回。  

6. **回溯**  
   - 若后续返回 `False`，把 `board[r][c]` 恢复为 `'.'`，并从三个集合中删除该数字。  

7. **结束**  
   - 当 `pos == len(empties)`，说明所有空格都填完，返回 `True`。  

### **代码**  

```python
from typing import List

class Solution:
    def solveSudoku(self, board: List[List[str]]) -> None:
        """
        使用集合记录行、列、宫格已出现的数字，实现 O(1) 合法性检查。
        整体思路仍是回溯，只是把重复遍历的开销降到了常数。
        """

        # 1. 初始化约束集合
        rows = [set() for _ in range(9)]      # rows[i] 保存第 i 行已经出现的数字
        cols = [set() for _ in range(9)]      # cols[j] 保存第 j 列已经出现的数字
        boxes = [set() for _ in range(9)]     # boxes[b] 保存第 b 个 3x3 小宫格的数字
        empties = []                           # 所有空格的坐标

        for i in range(9):
            for j in range(9):
                ch = board[i][j]
                if ch == '.':
                    empties.append((i, j))    # 记录空格位置
                else:
                    rows[i].add(ch)
                    cols[j].add(ch)
                    box_index = (i // 3) * 3 + (j // 3)
                    boxes[box_index].add(ch)

        # 2. 深度优先搜索（回溯）
        def dfs(pos: int) -> bool:
            """尝试填第 pos 个空格，全部填完返回 True"""
            if pos == len(empties):          # 所有空格都已填好
                return True

            r, c = empties[pos]
            b = (r // 3) * 3 + (c // 3)       # 计算所在小宫格的下标

            # 3. 依次尝试 1~9 中合法的数字
            for digit in map(str, range(1, 10)):
                if (digit not in rows[r] and
                    digit not in cols[c] and
                    digit not in boxes[b]):   # O(1) 检查

                    # 4. 写入并更新约束集合
                    board[r][c] = digit
                    rows[r].add(digit)
                    cols[c].add(digit)
                    boxes[b].add(digit)

                    # 5. 递归处理下一个空格
                    if dfs(pos + 1):
                        return True               # 找到完整解，直接返回

                    # 6. 回溯：撤销本次尝试
                    board[r][c] = '.'
                    rows[r].remove(digit)
                    cols[c].remove(digit)
                    boxes[b].remove(digit)

            # 没有任何数字可以填入当前空格，返回 False 让上一层回溯
            return False

        dfs(0)   # 从第一个空格开始搜索
```

下面列出前几次递归调用时集合的变化，帮助你体会 **集合+回溯** 的优势。  

| 步骤 | 空格坐标 `(r,c)` | 尝试的数字 | `rows[r]` / `cols[c]` / `boxes[b]` 变化 | 说明 |
|------|------------------|-----------|---------------------------------------|------|
| 0 | 初始收集 | - | `rows[0] = {'5','3'}`, `cols[2] = set()`, `boxes[0] = {'5','3'}` 等 | 所有已有数字已经放入集合 |
| 1 | 第一个空格 `(0,2)` | `'1'` → 被 `rows[0]` 拒绝（已含 `'5','3'`，不冲突）<br>`'2'` → 被 `cols[2]` 拒绝（列 2 已有 `'2'` 在 `(1,2)`）<br>`'4'` → **合法** | 把 `'4'` 加入 `rows[0]`, `cols[2]`, `boxes[0]`；`board[0][2]='4'` | 只查集合，几乎瞬间得到合法性 |
| 2 | 第二个空格 `(0,3)` | `'1'` → 被 `rows[0]` 拒绝（已有 `'5','3','4'`，不冲突）<br>`'6'` → **合法** | `rows[0]` 加入 `'6'`，`cols[3]` 加入 `'6'`，`boxes[1]` 加入 `'6'`；`board[0][3]='6'` | 同上 |
| 3 | 第三个空格 `(0,5)` | `'1'` → 合法 → 写入 `'1'` 并更新三集合 | `rows[0]` = `{'5','3','4','6','1'}` … | 继续递归 |
| … | … | … | … | … |
| 最后 | 所有空格填完，`pos == len(empties)` 返回 `True` | - | 所有集合里均包含 1~9（每行、每列、每宫格恰好 9 个数字） | 递归层层返回，`board` 成为最终解 |

如果在某一步所有 1~9 都在对应集合里出现，`for digit` 循环结束后直接返回 `False`，上一层会 **撤销** 已经写入的数字并尝试别的候选，从而实现**前向剪枝**，大幅削减搜索树的规模。

### **复杂度分析**  

- **时间复杂度**  
  - 每个空格只尝试最多 9 次，每次合法性检查是集合的 O(1) 操作。  
  - 最坏情况仍是指数级 `O(9^{m})`（`m` 为空格数），但因为集合剪枝极大，实际运行时间大约是暴力版的 **1/10~1/100**。  
- **空间复杂度**  
  - `rows、cols、boxes` 各 9 个集合，最多存 9*9 = 81 个字符 → **O(1)**（常数空间）。  
  - 递归深度同样不超过空格数 ≤ 81 → **O(81)**（亦可视作 O(1)）。

## 对比总结  

| 项目 | 解法一：暴力回溯 | 解法二：集合+前向剪枝 |
|------|----------------|----------------------|
| **核心思路** | 直接遍历每个空格，尝试 1~9 并每次遍历行/列/宫格检查合法性 | 预先用集合记录已出现的数字，合法性检查变为 O(1)，并在搜索过程中即时更新/撤销 |
| **时间复杂度** | 指数级，实际运行受大量重复检查影响，最坏约 `9^{81}`（理论） | 同样指数级但常数更小，实际约是暴力版的 10%~1% |
| **空间复杂度** | 递归栈 O(81)；额外无其他结构 → O(1) | 递归栈 O(81) + 三组集合（固定 27 个集合） → O(1) |
| **实现难度** | 简单直观，代码量少，适合初学者理解回溯概念 | 稍复杂，需要维护额外数据结构，但仍然是回溯的基本框架 |
| **学习收获** | ① 递归与回溯的基本流程 ② 如何在搜索过程中“尝试—撤销” | ① 利用 **状态压缩**（集合/位掩码）提升搜索效率 ② 前向剪枝的思想，如何在搜索前提前排除不可能的分支 |

### 最重要的收获  

- **回溯是解决组合搜索问题的通用框架**：先尝试、若冲突则撤销再尝试其他选项。  
- **利用约束信息可以大幅加速回溯**：把问题的“规则”转化为可快速查询的数据结构（如集合或位掩码），在每一步只做常数时间的合法性判断，就能把原本的“暴力”搜索变得实用。  

掌握了这两个层次的思路，你不仅能轻松解决数独，还能把同样的技巧迁移到 N‑皇后、字谜、排列组合等其它需要“尝试所有可能并剪枝”的算法题目中。祝学习愉快 🚀
